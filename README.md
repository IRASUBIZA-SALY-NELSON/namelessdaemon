# Chat App

Standalone real-time chat application extracted from TaskFlow.

## Stack
- **Frontend**: React + Vite (port 3001)
- **Backend**: Spring Boot + MongoDB + WebSocket/STOMP (port 8082)

## Run locally

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3001
